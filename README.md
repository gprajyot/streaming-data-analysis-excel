# 🎵 Streaming Data Analysis & Interactive Excel Dashboard

An Excel-based data analysis project that explores music streaming performance across artists, genres, countries, platforms, subscriptions, listeners, streams, and revenue.

## 🎯 Project Objectives

- Analyze monthly streaming trends
- Compare streaming platforms
- Identify top-performing artists
- Analyze genre performance
- Compare subscription segments
- Track important business KPIs
- Build an interactive Excel dashboard
- Present data-driven insights through charts and pivot-based analysis

## 📁 Workbook Structure

The Excel workbook contains:

- **Streaming Data** — source dataset with 500 records and 15 attributes
- **Monthly stream** — monthly streaming analysis
- **platform performance** — platform-level streams and revenue
- **subscription revenue** — subscription/segment analysis
- **top 5 artist** — top artists by revenue
- **KPI** — key performance indicators
- **Dashboard** — interactive dashboard with charts and KPI cards
- **Dashboard_Insights** — supporting dashboard analysis

## 📌 Dataset Fields

The source data includes:

`Stream ID`, `Date`, `Month`, `Artist`, `Listener Country`, `Region`, `Genre`, `Platform`, `Subscription`, `Streams`, `Unique Listeners`, `Skips`, `Playlist Adds`, `Completion Rate`, and `Revenue`.

## 📈 Dashboard Components

The dashboard brings together:

- Total Streams
- Total Revenue
- Unique Listeners
- Average Completion Rate
- Monthly Stream Trend
- Platform Stream vs Revenue Analysis
- Top 5 Artists by Revenue
- Genre Performance

## 🔍 Key Insights

- **Mobile App** has the highest total streams among the platforms in the source data.
- **Smart TV** generates the highest total revenue among the platforms.
- **Ambient** is the highest-streamed genre.
- **Orin Fable** has the highest total revenue among artists.
- **Premium** has the highest revenue among subscription categories.
- **November** records the highest monthly stream volume.
- The overall average completion rate is **76.23%**.

See [`documentation/project-insights.md`](documentation/project-insights.md) for more details.

## 🚀 How to Use

1. Download `data/Streaming_Data_Analysis_Dashboard.xlsx`.
2. Open it in Microsoft Excel.
3. Start with the **Dashboard** sheet.
4. Explore the analysis sheets for the supporting calculations.
5. Use filters/slicers where available to interact with the analysis.
